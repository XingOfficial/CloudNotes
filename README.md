# 云笔记——简洁高效的云端笔记应用

## 应用简介

云笔记是一款轻量级、纯原生的 Android 笔记应用，专注于快速记录和云端同步。无需复杂的注册流程，邮箱验证码即可登录，所有笔记实时保存在云端，换设备也不丢失。界面简洁无广告，启动速度快，是你记录灵感、备忘、待办的理想工具。

## 核心功能

### 快速记录
- 新建笔记只需一步，标题和内容自由填写
- 支持空标题（自动以内容预览作为标题显示）
- 大文本编辑区域，行间距舒适，长时间书写不累眼
- 笔记按更新时间自动倒序排列，最近编辑的永远在最前面

### 邮箱验证码登录
- 无需设置密码，邮箱+6 位验证码即可登录/注册
- 注册时可自定义昵称，不填则自动使用邮箱前缀
- 登录状态持久化，7 天内免登录
- 支持一键退出登录

### 云端同步
- 所有笔记实时保存在云端服务器
- 创建、编辑、删除均即时同步
- 换手机、重装应用，登录后笔记自动恢复
- 采用 Bearer Token 鉴权，数据安全有保障

### 一键分享
- 长按笔记条目，弹出操作菜单
- 分享调用系统分享面板，可发送到微信、QQ、短信、邮件等任意应用
- 分享内容自动包含标题和正文

### 安全删除
- 长按笔记 → 选择删除
- 删除前二次确认，防止误操作
- 删除后自动刷新列表

### 下拉刷新
- 笔记列表支持下拉刷新，随时获取最新数据
- 加载状态清晰可见

### 笔记搜索
- 列表页顶部搜索框，实时过滤标题和内容
- 搜索无结果时显示友好提示

### 多种排序
- 按更新时间（新→旧/旧→新）
- 按创建时间（新→旧）
- 按标题（A→Z）

### 自动保存
- 编辑已有笔记时，输入停止 2 秒后自动保存
- 离开页面时也会触发自动保存
- 底部显示"已自动保存：时间"

### 字数统计
- 编辑页底部右下角实时显示总字数（标题+内容）

### 导出笔记
- 编辑页顶部"导出"按钮，或列表页长按菜单中的"导出"选项
- 导出为 Markdown 格式文本，可分享到任意应用

## 页面结构

1. **登录页**：顶部 Logo+应用名，Tab 切换登录/注册，邮箱、验证码输入框，发送验证码带 60 秒倒计时
2. **笔记列表页**：顶部导航栏（显示昵称+退出按钮），搜索框+排序按钮，卡片式笔记列表，右下角新建笔记按钮
3. **笔记编辑页**：顶部返回+导出+保存按钮，大标题输入框，正文编辑区，底部显示创建/更新时间+字数统计

## 使用指南

### 首次使用

1. 打开应用，默认进入登录页
2. 切换到注册 Tab，输入邮箱，点击发送验证码
3. 查收邮件中的 6 位验证码，填入验证码框
4.（可选）填写昵称，点击注册
5. 注册成功后自动进入笔记列表

### 已有账号

1. 在登录 Tab 输入注册时的邮箱
2. 点击发送验证码，查收邮件填入验证码
3. 点击登录即可

### 创建笔记

1. 点击右下角新建笔记按钮
2. 输入标题（可选）和内容
3. 点击右上角保存
4. 保存成功后自动返回列表并刷新

### 编辑笔记

1. 在列表中点击任意笔记卡片
2. 修改标题或内容
3. 点击保存（或等待 2 秒自动保存）

### 分享/删除/导出笔记

1. 在列表中长按任意笔记卡片
2. 弹出菜单中选择分享、导出或删除
3. 分享/导出：选择目标应用即可发送
4. 删除：在确认弹窗中点击删除

### 搜索笔记

1. 在列表页顶部搜索框输入关键词
2. 列表实时过滤显示匹配的笔记
3. 清空搜索框恢复显示全部笔记

### 排序笔记

1. 点击搜索框右侧的"排序"按钮
2. 选择排序方式
3. 列表立即按新方式排序

### 退出登录

1. 在笔记列表页，点击右上角退出登录
2. 确认后返回登录页

## 常见问题

**Q：收不到验证码怎么办？**
A：请检查邮箱是否正确，查看垃圾邮件文件夹。如仍未收到，可等待 60 秒后重新发送。若无效，请加群 677010442 反馈。

**Q：提示"无法解析服务器域名"怎么办？**
A：这可能是当前网络的 DNS 解析问题。应用已内置 Cloudflare DNS 兜底，如仍失败，请尝试切换 WiFi/移动数据，或在手机设置中将 DNS 改为 1.1.1.1。

**Q：笔记会丢失吗？**
A：所有笔记实时保存在云端服务器，只要能登录账号，笔记就不会丢失。建议在有网络的环境下使用。

**Q：支持离线使用吗？**
A：当前版本需要联网才能加载和保存笔记。离线模式将在后续版本中支持。

**Q：如何修改昵称？**
A：当前版本暂不支持修改昵称，可退出后重新注册新账号。
